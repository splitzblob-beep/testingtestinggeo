# Click Guide

Learn a level's click pattern by seeing exactly where to click.

## What you see in the level
- **Cyan dot** — press jump here (orange = player 2 in dual).
- **Green trail** — keep holding along this path; the hollow ring at the end is where you let go.
- **Shrinking white ring** — around the *next* click. It closes onto the dot right as you reach it, so you can see the timing coming.
- **Faint white marks** — where you actually clicked this attempt, to compare.

## How it learns
The guide is built from **your own** runs. Each attempt is recorded; when you die,
the last few blocks before the death are thrown away (that's where the mistake was).
If you got further than the guide already covered, that stretch is saved as the new guide.
Beating the level saves the whole run. Practice mode and start positions work too, so you
can build up a hard level section by section.

## Tips
- Play a section in practice until you pass it once, then switch to normal mode and follow the markers.
- Turn off **Learn from my runs** in settings once you have a clean guide, so a sloppy run can't replace it.
- **Clear Guide** in the pause menu wipes this level's markers.
